# Guía para agentes

Este repositorio es el perfil público de GitHub, no una aplicación ejecutable.

## Antes de cambiar

- Lee `README.md` y revisa que las imágenes referenciadas existan en `assets/`.
- Conserva la información profesional y no inventes experiencia, estudios o certificaciones.
- No añadas datos privados, credenciales ni estadísticas no verificadas.
- Mantén enlaces externos, texto alternativo y el comportamiento de movimiento reducido.

## Verificación

Revisa los enlaces Markdown y la existencia de los assets referenciados. No requiere instalación, build ni tests de aplicación.
